# 말씀암송 놀이터 · 주평예수교회

주평예수교회 교우들을 위한 말씀 암송 앱이에요. 교회 말씀암송 인쇄물 (1)–(4)의 42구절을
빈칸 채우기, 순서 맞추기, 직접 써보기, 퀴즈로 재미있게 외워요.

**앱 열기:** https://herrhanch33.github.io/memorizeword/

폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.
- iPhone: Safari → 공유 → 홈 화면에 추가
- Android: Chrome → ⋮ → 홈 화면에 추가

## 어떻게 외우나요

- **구절 보기:** 단어를 조금씩 가리면서 읽고, 읽어주기로 들어요.
- **빈칸 채우기 · 순서 맞추기 · 직접 써보기:** 세 가지를 모두 통과하면 그 구절을 정복해요.
- **오늘의 도전:** 10문제 퀴즈. 세 문제 연속 정답이면 보너스.
- **난이도 4단계:** 쉬움 → 보통 → 어려움 → 오직말씀. 어려움부터는 장·절이 숨겨져요.
  난이도마다 따로 정복해요.
- **내 진도 저장:** 닉네임과 비밀번호 4자리를 정하면 진도가 저장되고, 다른 폰에서도
  이어서 할 수 있어요. 친구들 순위표에도 올라가요.

## 이 저장소

`index.html` 하나가 앱 전체예요. `sw.js`는 한 번 열고 나면 인터넷 없이도 열리게 해 줘요.
진도 저장과 순위표는 교회 홈랩에서 돌아가는 작은 서버(`sync-server/`, 별도 보관)가 맡아요.

성경 본문은 개역개정이에요. 교회 암송 모임 안에서만 쓰려고 만들었어요.
